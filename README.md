# brunodelatea.github.io

Página de links do [@brunodelatea](https://instagram.com/brunodelatea): **https://brunodelatea.github.io**

Um `index.html` só, sem framework, sem analytics. Lista os repositórios públicos ao vivo pela API do GitHub e os
"em breve" a partir de [`scripts/planned.json`](https://github.com/brunodelatea/brunodelatea/blob/main/scripts/planned.json)
do repositório do perfil (uma fonte só para os dois lugares).

## Trocar a foto

Substitua `foto.jpg` (quadrada, 512 px ou mais) e faça o push. Nada mais precisa mudar.

## Ligar o YouTube

Em `index.html`, no botão do YouTube: tire a classe `breve`, o `aria-disabled` e o `onclick`, e ponha a URL do canal no `href`.
